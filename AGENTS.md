# Codex repository instructions

Before working in this repository, read [`CLAUDE.md`](./CLAUDE.md). Treat all of
its repository-wide behavioral guidelines, commands, architecture notes, and PR
rules as instructions for Codex as well. `CLAUDE.md` remains the canonical copy
so that the two instruction files cannot drift apart.

When a directory contains a more specific `CLAUDE.md`, read that file before
changing files in that directory tree and apply it in addition to these
repository-wide instructions.
