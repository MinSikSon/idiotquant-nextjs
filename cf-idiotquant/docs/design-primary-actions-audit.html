03. 주요 행동의 시각적 위계

검색·추가·저장은 채움색과 굵기로 강조하고, 공유·설명·닫기는 중립색으로 구분합니다. 종목 분석에는 눈에 보이는 검색 실행 버튼을 추가했습니다.

기준 작업본: origin/main 56ffe22f. 01 명암비 · 02 상호작용·상태 구분

적용 원칙

  • 현재 작업 영역에서 사용자가 다음 단계로 진행하는 동작을 강조합니다. 비교의 날짜 추가와 종목 추가는 서로 다른 단계에 속합니다.
  • 공통 주요 버튼 스타일은 최소 44px 높이, 채움색, 굵은 글자와 키보드 포커스를 제공합니다. 기본·hover·비활성 상태를 구분합니다.
  • 새로고침·공유·설명·닫기는 중립색을 사용합니다. 자동 계산되는 화면에 별도 계산 버튼을 만들지 않습니다.

종목 분석Enter에만 의존하던 검색에 실행 버튼을 추가했습니다. 버튼과 Enter는 같은 자동완성 선택값으로 검색합니다. 결과 전에는 입력창에, 결과 후 검색창이 닫혔을 때는 상단의 종목 검색에 강조를 둡니다. 검색창이 열리면 상단 버튼은 중립색의 검색 닫기로 바뀝니다. 중복 닫기 버튼을 제거했습니다.components/searchAutoComplete.tsx
app/(analyze)/analyze/page.tsx
종목 비교날짜 추가와 종목 추가에 공통 주요 버튼을 적용했습니다. 모바일에서 종목 추가의 텍스트도 표시해 아이콘만으로 행동을 추측하지 않게 했습니다. 입력·개수·조회 중 비활성 조건은 유지합니다.app/(compare)/compare/page.tsx

검증

  • npm run check: 린트 오류 0개, 타입 검사 및 테스트 586개 통과. 기존 린트 경고는 유지되며 Worker 통합 suite는 별도입니다.
  • npm run build: Webpack 프로덕션 빌드 통과.
  • 예시 데이터 화면에서 빈 입력 비활성, 자동완성 두 번째 항목 선택 후 버튼/Enter의 검색 대상 일치, 제안이 없는 직접 입력과 Space 실행을 확인했습니다. 각각 1회만 실행됐습니다. 검증용 임시 화면과 생성된 타입 캐시는 제거했습니다.
  • 실제 비로그인 분석 화면에서 검색 버튼 → 삼성전자 분석 → 상단 종목 검색 → 중립색 검색 닫기 → Escape와 초점 복원을 확인했습니다.
  • 실제 비교 화면에서 날짜 입력·추가 후 종목 검색과 종목 추가가 활성화되는 것을 확인했습니다. 테스트로 추가한 날짜는 제거했습니다.
  • 계산기 설명 토글의 중립 배경·밑줄, 홈의 밝은·어두운 테마 주요/보조 버튼, 390px 모바일 및 데스크톱 배치를 확인했습니다.

범위와 한계

금융·공통 UI의 주요 행동을 대상으로 했습니다. 실제 가계부 저장이나 계좌·매매 동작은 실행하지 않았으며 가계부는 코드 검토와 정적 검사로 확인했습니다. 인증·계산·저장 API와 자동매매 로직은 변경하지 않았습니다. 이번 기록은 서비스 전체 접근성 인증을 뜻하지 않습니다.
