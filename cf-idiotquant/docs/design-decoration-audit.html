구분에 필요한 표현만 남기기

홈·분석 안내·계산기·발굴 화면에서 정보 역할이 겹치는 선·배경·그림자·유리 효과를 줄였다. 앞 단계에서 정리한 여백과 제목, 숫자, 링크 단서가 그룹과 동작을 전달하도록 했다.

근거: 큰 효과를 만드는 작은 UI 디자인 팁들의 불필요한 장식 제거 원칙. 변경은 네 개 화면의 표현에 한정한다.

정리한 표현

화면이전적용
홈 미리보기반투명 표면과 12px 배경 블러테마별 불투명 패널 표면으로 교체. 표의 경계와 행 구분선은 유지
홈 도구 안내각 링크 카드의 테두리·채움·둥근 상자테두리와 기본 채움을 제거. 여백·순서 번호·제목·화살표로 구조를 전달하고 hover 배경과 키보드 포커스는 유지
분석 안내세 관점의 위 구분선, 모델 설명마다 별도 카드 경계·채움제목·번호·간격으로 그룹을 구분. 모델 가정 주의문을 구분하는 내부 선은 유지
계산기영문 섹션 레이블 옆의 반복 수평선선만 제거. 섹션 제목·레이블과 조건/결과 간격은 유지
발굴표·카드·선택 버튼·추가 동작의 shadow-sm, 보조 분석 버튼의 강한 hover 채움작은 그림자 10곳을 제거하고 보조 분석 동작 hover를 중성 표면으로 변경. 선택 밑줄·색상·텍스트와 실제 경계는 유지
발굴 필터 하단반투명 고정 바와 배경 블러불투명 테마 표면 사용. 상단 구분선과 적용 동작은 유지

남긴 표현의 이유

  • 입력 테두리와 포커스는 입력 위치와 현재 조작 대상을 전달한다.
  • 표 경계·행 구분선은 서로 다른 데이터 행과 묶음을 구분한다.
  • 선택 배경·밑줄·선택됨 텍스트는 사용자의 현재 조건을 전달한다.
  • 로딩 스피너·스켈레톤은 대기 상태를 전달한다. 제거하지 않았다.
  • 팝오버·메뉴의 그림자는 다른 내용 위에 떠 있는 계층을 구분한다. 발굴 툴팁·메뉴의 shadow-lg는 유지했다.
  • 홈의 브랜드 소개용 3D와 게임·관리자 전용 화면은 이번 변경에 포함하지 않았다.

검증

npm run check에서 타입 검사와 테스트 586개가 통과했고, lint 오류는 0개였다(기존 경고 129개). npm run build도 통과했다. 생성 CSS에서 홈 미리보기의 불투명 표면, 도구 안내의 경계·채움 제거, 분석 모델·단계의 장식 제거를 확인했다.

브라우저 자동화 연결 오류와 Mac 잠금으로 이번 실행의 화면 직접 검증을 수행하지 못했다. 소스와 생성 CSS로 확인했으며, 화면 크기별 읽기 흐름과 hover·포커스 모양은 직접 확인한 것으로 표시하지 않는다. 다음 회귀 점검에서 확인할 공백으로 남긴다.

동작·조회·저장 로직은 수정하지 않았다. 기존 회귀 테스트 통과는 화면 크기별 읽기 흐름이나 hover·포커스 모양의 직접 확인을 대신하지 않는다.
