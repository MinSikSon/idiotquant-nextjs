# 기업 로고 등록

관리자로 국내 종목 분석 페이지를 열면, 로고 서버에서 `404`가 확인된 종목의 대체 아이콘에 `+` 버튼이 표시됩니다. 일반 사용자 화면 미리보기에서는 표시하지 않습니다.

버튼을 누르고 기업 홈페이지 URL을 입력하면 헤더 로고 이미지, 사이트 아이콘, 공유 이미지를 순서대로 탐색합니다. 직접 이미지 URL을 입력할 수도 있습니다. 미리보기에서 기업 로고인지 확인한 뒤 등록하면 기존 로고 서버에 저장하고 화면을 갱신합니다. 자동 탐색이 실패하면 직접 이미지 URL을 사용합니다.

## 배포 설정

프론트엔드 서버의 실행 환경에 `KR_LOGO_ADMIN_PASSWORD`를 비밀 환경변수로 설정합니다. 값은 기존 로고 서버의 관리자 비밀번호입니다. `NEXT_PUBLIC_` 접두사를 붙이지 않습니다. 로컬 개발에서는 Git에서 제외된 `.env.local`에 설정합니다.

NextAuth 세션의 `role === "admin"`을 서버에서 확인하고, 동일 출처의 요청만 등록을 허용합니다. 기존 서버의 `POST https://kr-logo-api.tofu89223.workers.dev/upload`에 `bizNo`(6자리 종목코드), `corpName`, `format`, `imageBase64`, `adminPw`를 보냅니다. 비밀번호와 원본 서버 응답은 브라우저에 전달하지 않습니다.

수집된 이미지는 브라우저에서 최대 512px PNG로 변환합니다. SVG도 PNG로 변환해 저장하며, 저장 직전 기존 로고가 생겼는지 다시 조회합니다. 원본 로고 서버에는 변경이 필요하지 않습니다.

이미지는 존재하지만 흰색 로고가 흰 배경에 묻히는 경우는 `404`가 아니므로 등록 버튼이 표시되지 않습니다. 기존 로고 교체는 기존 관리 화면에서 처리합니다.
