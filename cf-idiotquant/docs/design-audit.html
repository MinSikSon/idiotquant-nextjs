01. 텍스트와 컨트롤의 명암비

공통 헤더·내비게이션·검색·빠른 이동·잔고 공용 UI의 대비를 보정했습니다. 분석 화면의 검색창 전용 스타일과 홈의 다크 모드 주요 버튼도 함께 수정했습니다.

구현 및 로컬 검증 완료 기준 작업본: origin/main 1c8d7cf1. 기존 작업 폴더의 미커밋 변경은 보존하고 별도 작업 트리에서 구현했습니다.

적용 기준

  • 일반 텍스트와 placeholder는 4.5:1 이상을 기준으로 검증합니다.
  • 컨트롤의 식별에 필요한 경계·아이콘·포커스는 인접 배경과 3:1 이상을 확보합니다. 장식용 카드 구분선을 일괄적으로 진하게 만들지 않습니다.
  • 비활성 컨트롤은 기준 예외입니다. 금융 데이터의 상태색이나 게임 전용 팔레트는 이번 수정 대상에 포함하지 않습니다.

측정 결과

Chrome 로컬 렌더링에서 계산된 CSS 색상을 읽고 sRGB 상대 휘도 공식으로 계산했습니다. 전환 애니메이션이 끝난 상태에서 측정했으며, 반투명 표면은 배경색을 합성했습니다. 아래 값은 표시용 반올림이며 판정에는 반올림 전 값을 사용했습니다.

코드 색상 기준으로 홈의 다크 주요 버튼 채움과 바탕은 3.40:1입니다. 공통 헤더에서 사용하던 #a3a3a3 글자는 흰색 배경에서 2.52:1이었으며, #525252로 변경하면 7.81:1입니다. 수치는 해당 색상 조합의 계산값이며 모든 호출 위치의 실제 화면 측정을 뜻하지 않습니다.

#a3a3a3 / #1b1819 · 6.99:1

검증과 한계

  • npm run check: 린트 오류 0개, 타입 검사 통과, 단위 테스트 586개 통과. 기존 린트 경고는 유지됩니다. Worker 통합 suite는 기본 실행 대상에서 제외됩니다.
  • npm run build: Webpack 프로덕션 빌드 통과.
  • Chrome에서 390×844 모바일과 1440×900 데스크톱, 밝은·어두운 테마를 확인했습니다. 자동완성 선택, 결과 없음, Escape, 빠른 이동 열기·닫기와 테마 전환을 확인했습니다.
  • 잔고의 로그인 이후 화면은 실제 계좌로 조작하지 않았습니다. 공용 컴포넌트의 코드와 색상 조합을 검토했습니다.
  • 이번 보고서는 첫 번째 적용 항목의 기록입니다. 서비스 전체의 접근성 적합성 인증이나 모든 데이터 상태의 대비 검증을 의미하지 않습니다.
