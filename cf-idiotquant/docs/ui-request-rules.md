# 반복 UI 수정 방지 규칙

2026-11-17 기준. 이번 사용자의 직접 요청과 최근 main 반영 이력에서 반복된 화면 조정을 정리한다. 금융 화면을 새로 만들거나 수정할 때 적용한다. 새로운 사용자 요청이 우선하며, 게임·관리자 화면에 금융 화면의 배치를 일괄 적용하지 않는다. 모바일 글자·간격의 공통 배율은 서비스 전체에 적용한다.

## 주요 동작은 상단에 모은다

- `비교에 추가`처럼 현재 종목에 바로 실행하는 주요 동작은 공통 `PageHeader`의 `primaryAction` 슬롯에 둔다.
- 버튼 하나를 위해 탭과 본문 사이에 별도 행을 만들지 않는다. 버튼 행 때문에 분석 결과가 아래로 밀리지 않게 한다.
- 검색은 공통 헤더의 검색 진입점을 사용한다. 같은 검색 버튼·입력·계정 메뉴를 모바일 화면에 중복 노출하지 않는다.
- 모바일 공통 헤더에서 종목 검색은 우상단 `…` 바로 왼쪽에 둔다. 새로고침처럼 페이지별로 달라지는 버튼은 검색 왼쪽에 배치해 화면을 이동해도 검색 위치가 바뀌지 않게 한다.
- 모바일 공통 검색창은 가로 드래그 중 손가락을 따라 움직인다. 충분히 밀고 손을 떼면 밀던 방향으로 닫히고, 짧거나 취소된 드래그는 제자리로 돌아온다. 세로 스크롤과 검색어 편집 영역의 드래그는 기존 동작을 유지한다.
- 스크리너 본문에는 ‘발굴 종목 검색’과 정렬 선택 행을 다시 추가하지 않는다. 검색은 공통 헤더, 목록 정렬은 지표 헤더를 사용한다(2026-11-18 중복 버튼 제거 요청).
- 보조 작업은 기존 페이지 도구 메뉴를 사용한다. 주요 동작을 보조 메뉴 안에 숨기지 않는다.
- 모바일 종목 분석에서는 종목명·티커·현재가 공간을 확보하도록 `ETF에 담기`·`초안 보기`·`비교에 추가`를 상단 `…` 메뉴를 열었을 때 표시한다. 데스크톱 분석에서는 상단 바로가기를 사용한다.

- 스크리너 사용 가이드와 수집 중·이전 데이터 보완 안내는 상단 `…` 페이지 도구 메뉴에 둔다. 본문에 접힌 안내 카드나 별도 행으로 다시 노출하지 않는다.

## 스크리너는 로그인 전후 같은 화면을 사용한다

- 헤더·시장 탭·필터·결과 보기(목록·카드·자산 비율)는 로그인 여부와 관계없이 같은 구성을 사용한다(2026-11-18 직접 요청).
- 비로그인 전용 추천 카드나 별도 고정 필터를 만들지 않는다. 미리보기 개수와 관심종목 저장 등 계정이 필요한 동작만 기존 제한을 적용한다.

## 투자 기준 월드컵은 선택지만 간결하게 보여준다

- 상단은 제목·진행 수치와 얇은 진행 막대만 두고, 중앙의 둥근 단일 무대에 질문과 두 일러스트 선택지를 모은다. 트로피·ROUND 문구·단계명·VS 배지·반복 화살표는 노출하지 않는다(2026-11-19 첨부 화면 기반 후속 요청).
- 선택지 문구는 ‘흑자만 / 적자도 포함’처럼 짧게 유지하고, 선택된 카드에만 체크를 표시한다. 하단은 원형 이전 버튼과 건너뛰기로 단순하게 구성한다.
- 단순 필터 버튼처럼 보이지 않도록 두 후보의 일러스트·색조를 구분하고, 선택 카드의 호버·누름·라운드 전환 반응을 제공한다. 움직임 줄이기 설정을 존중한다.
- 카드 안에 선택 안내·설명·같은 뜻의 필터 결과를 반복하지 않는다. 수치 조건은 선택지에 남기고, 배경 설명과 주의점은 기존 ‘선택 기준 자세히’에 둔다.
- 월드컵 상단의 사용법 문장을 반복하지 않는다. 글자를 작게 줄이는 대신 중복 텍스트를 제거한다.

## 비로그인 홈에서는 일러스트가 선택 버튼이다

- 짧은 질문 아래 종목 검색·종목 발굴을 각각 누를 수 있는 일러스트로 보여준다. 별도 큰 장식 이미지와 같은 동작을 반복하는 버튼 행을 두지 않는다.
- 모바일에서는 두 선택지와 기업 로고가 있는 첫 예시 종목을 스크롤 없이 볼 수 있도록, 브라우저 주소창과 앱의 하단 탐색바가 차지하는 높이까지 확인한다. 이용 방법은 펼쳐서 볼 수 있게 둔다.
- 관심종목 예시는 한국·미국의 대형주와 저평가주로 나눈다. 종목별 현재가와 전략별 적정주가·차이율을 기본 화면에 함께 표시한다. 현재가 대신 최신 스캔 가격을 쓰는 경우에는 스캔 기준가와 날짜를 밝힌다.
- 금화 낙하 효과는 선택 영역 뒤에서 보여준다. 동전이 커져도 카드 문구와 종목 목록의 가독성은 유지하고, 움직임 줄이기 설정에서는 정지 상태로 표시한다.

## 접힌 영역은 한 줄 요약 크기로 만든다

- 저평가 신호처럼 접을 수 있는 요약은 충족 개수·짧은 결론·펼침 표시를 같은 행에 배치한다.
- 접힌 상태에는 펼친 패널용 16~24px 상하 패딩이나 최소 높이를 남기지 않는다. 모바일 저평가 신호는 상하 패딩 0, 좌우 12px, 아래 여백 8px을 기준으로 한다.
- 한 줄 문구라면 조작 영역 최소 44px과 테두리 정도의 높이로 표시한다. 긴 문구·글자 확대 시에는 자연스럽게 높아지도록 하고 고정 높이로 내용을 자르지 않는다.
- 펼친 상태에는 상세 지표를 읽을 여백을 유지한다. 접을 때는 상세 내용과 그 내용에만 필요한 여백이 함께 사라져야 한다.
- 저평가 신호를 펼쳐도 상단 요약 행의 높이·패딩·문구 위치는 접힌 상태와 같게 유지한다. 상세 영역의 구분선은 요약 행 바로 아래에 두고, 상세 여백은 구분선 아래 영역 안에만 둔다.

## 비교 상세도 짧은 행으로 표시한다

- 모바일 비교 카드의 접힌 요약은 종목명·가격·변화율 한 줄을 유지한다.
- 펼친 상태에서도 날짜·가격·변화율을 같은 행에 놓고, 동일한 날짜·가격 기준 설명을 반복하지 않는다. 실제 거래일이 선택일과 다를 때만 거래일을 추가 표시한다.
- 지표는 라벨·값을 나란히 놓고 행 간격을 줄인다. 글자를 줄이거나 터치 영역을 축소해 밀도를 높이지 않는다.
- 당시 시총·출처는 별도로 펼쳐 확인하게 하되, 조회 오류·종가 대체 안내는 바로 표시한다.
- 긴 종목명과 글자 확대 시 줄바꿈을 허용한다(2026-11-18 비교 상세 높이 축소 직접 요청).

## 자산의 자동매매 표시는 아이콘으로 유지한다

- 보유 종목의 자동매매 연결 표시는 종목명 옆 로봇 아이콘 하나로 표시한다. 텍스트 배지나 별도 줄을 추가해 행 높이를 늘리지 않는다(2026-11-19 후속 요청).
- 상태·그룹명은 아이콘의 접근성 이름과 툴팁에 제공한다. 자산·자동매매·주문내역·계정 탭은 작은 화면에서도 동일한 선형 아이콘을 표시하고, 자동매매에는 같은 로봇 아이콘을 쓴다.

## 모바일 첫 화면에 실제 데이터를 보여준다

- 제목·버튼·탭·설명·카드의 여백을 각각 보는 데 그치지 말고, 합쳐진 세로 높이를 확인한다. 핵심 수치와 첫 분석 항목이 불필요하게 아래로 밀리지 않게 한다.
- 시장 지표와 관심종목은 짧은 행 중심으로 구성한다. 지표마다 큰 카드나 넓은 빈 공간을 반복하지 않는다.
- 국내 종목의 위험 점검 목록은 항목명·수치·상태를 공간이 허용하는 한 같은 줄에 배치한다. 수치나 상태를 되풀이하는 설명과 ‘자료 없음’ 옆의 대시는 생략한다. 판정 기준이나 추가 설명은 요약 행 전체를 눌러 펼치고, 문구가 길면 줄바꿈을 허용한다.
- 현재가 기준선은 전체 모델 행을 관통하는 하나의 연속 세로선으로 표시하고, 모델명은 각 차트 왼쪽의 공통 열에 둔다. 모바일에서도 이름을 차트 위로 분리하지 않는다.
- 현재가·적정가 비교 차트는 동일한 가격 축에 두 값을 서로 다른 모양으로 표시하고, 연결 구간과 현재 시세 대비 차이율을 함께 보여준다. 상세 모델의 과거 계산 기준가와 혼동하지 않도록 기준을 명시한다.
- 적정가치 모델 행과 차트는 숫자·라벨을 읽을 공간만 확보한다. 고정 높이와 위아래 패딩이 겹쳐 생기는 빈 공간을 줄인다.
- 모바일 글자·간격은 스크리너만 별도로 축소하지 않고 서비스 전체의 공통 기준을 따른다. 기본 배율은 `100%`로 유지하고, 정보 밀도는 중복 설명·패딩·행 간격을 줄여 확보한다. 브라우저 배율과 사용자 글자 확대를 그대로 지원한다.
- 화면별 정보 밀도는 패딩·행 간격·중복 요소를 조절해 높인다. 공통 배율 위에 글자 축소를 중복 적용하지 않는다. 주요 터치 영역은 최소 44px, 모바일 입력 글자는 최소 16px로 유지하며 사용자 글자 확대를 막지 않는다.
- 분석의 저평가 요약·읽는 법·적정주가 모델명·가격도 공통 배율을 따르도록 `rem`을 사용한다. 해당 영역의 고정 `px` 글자 크기를 재도입하지 않고, 입력 글자의 최소 16px은 유지한다.
- 모바일 스크리너 목록은 기본 배율에서도 핵심 지표를 한 행에 유지한다. 종목명·티커·거래 배지는 공간이 있으면 같은 줄에 두고, 빈 보조 줄을 예약하지 않는다. 긴 종목명이나 글자 확대 시에는 보조 정보의 줄바꿈을 허용한다.

## 나만의 ETF는 카드 단위로 넘긴다

- 공개 피드는 공통 탐색바 사이의 화면 높이를 사용하고, 본문 제목 머리말과 피드 탭은 생략한다. 모바일에서는 피드가 가로 폭을 채우고, 넓은 화면에서는 카드 열을 가운데에 둔다. 위아래로 넘기는 안내와 버튼을 표시하고, 공유는 좋아요 옆 아이콘으로 둔다.

- 피드를 세로로 밀면 다음 ETF 카드의 상단에 맞춰 멈춘다. 카드 내용을 상단에서 시작하고, 종목이나 주가 비교를 펼쳤을 때는 카드 내부의 긴 내용도 이어서 읽을 수 있게 한다.
- 첫 슬라이드에 기대 수익률, 생성 후 실제 주가 수익률, 전략별 수익률과 전체 구성 종목을 표시한다. 옆 슬라이드에는 종목명과 가격 지표를 종목당 1~2줄로 표시하고, 공통 항목명과 기준일은 각각 한 번만 표시한다. 자료 재조회는 공통 버튼 하나로 제공한다.

## 관심종목 시작 화면은 목록부터 보여준다

- 로그인 후 시작 화면은 내 관심종목과 가격·적정주가를 바로 보여준다.
- 목록 앞에 별도 ‘오늘’ 소개, 지난 확인 이후 변화 카드, 확인 완료·수동 새로고침 버튼을 다시 추가하지 않는다.
- 최초 진입과 창으로 돌아왔을 때 자동으로 조회하고, 조회 실패 시에만 다시 불러오기 버튼을 제공한다.

## 헤더와 탭은 현재 대상을 유지한다

- 분석·공통 탐색에서 선택 상태가 유지되는 버튼과 탭은 배경색과 함께 안쪽 그림자로 눌린 상태를 표시한다. 선택된 버튼을 다시 누를 때도 눌림 피드백이 보이도록 한다.

- 종목명·티커·현재가는 모바일에서 현재 분석 대상을 알 수 있도록 유지한다.
- 작은 화면의 분석 탭은 종목 정보 아래에 두고, 스크롤 중에도 탭 전환을 사용할 수 있게 한다.
- 데스크톱 분석 화면은 적정가치·주요 지표·위험 점검·재무 흐름을 같은 폭의 네 열로 나란히 보여준다. 분석 결과는 공통 좌우 패딩을 유지하면서 창 너비에 맞춰 네 열을 함께 넓힌다. 각 열의 제목은 해당 본문 위에 고정하고, 본문은 열마다 독립적으로 세로 스크롤할 수 있게 한다.
- 스크롤 시 기존 헤더의 종목 정보를 공통 고정 상단바로 이어 표시한다. 종목 정보를 잃거나 동일 정보를 여러 행에 계속 반복하지 않는다.
- 헤더·본문의 좌우 시작선은 공통 너비 프리셋을 따른다. 컨테이너 패딩 위에 동일한 바깥 여백을 중첩하지 않는다.
- 모바일 공통 로고는 화면 맨 위에서 같은 좌우·세로 위치에 둔다. 페이지 제목·요약이나 고정 탭 때문에 로고 행 높이가 달라져도 로고 위치는 동일하게 유지한다.

- 스크리너의 시장·필터 방식·결과 보기 탭은 analyze와 같은 청록색 글자와 얇은 선택 밑줄로 구분한다(2026-11-18 직접 요청). 시장 전환은 로고·페이지 제목 행 아래의 공통 고정 헤더 탭 슬롯을 사용하고, 목록·카드·자산 비율 전환은 결과 바로 위에 표시한다. 중첩된 구분선은 추가하지 않는다.
- 스크리너는 스크롤 시 로고·페이지 제목 행을 접고, 좌상단 고정 상단바에 페이지 제목과 현재 시장·조건에 맞는 종목 수를 이어 표시한다. 로딩·조회 실패 상태에는 이전 종목 수 대신 해당 상태를 표시한다.

- 포트폴리오의 국가·계좌 선택 영역이 스크롤로 상단바 뒤로 사라지면 모바일 좌상단에 현재 국가·계좌 요약을 표시한다. 요약을 누르면 같은 선택 기능을 사용할 수 있어야 하며, 맨 위로 돌아오면 본문 선택 영역을 사용한다.
