# 반복 UI 수정 방지 규칙

2026-11-17 기준. 이번 사용자의 직접 요청과 최근 main 반영 이력에서 반복된 화면 조정을 정리한다. 금융 화면을 새로 만들거나 수정할 때 적용한다. 새로운 사용자 요청이 우선하며, 게임·관리자 화면에 금융 화면의 배치를 일괄 적용하지 않는다. 모바일 글자·간격의 공통 배율은 서비스 전체에 적용한다.

## 주요 동작은 상단에 모은다

- `비교에 추가`처럼 현재 종목에 바로 실행하는 주요 동작은 공통 `PageHeader`의 `primaryAction` 슬롯에 둔다.
- 버튼 하나를 위해 탭과 본문 사이에 별도 행을 만들지 않는다. 버튼 행 때문에 분석 결과가 아래로 밀리지 않게 한다.
- 검색은 공통 헤더의 검색 진입점을 사용한다. 같은 검색 버튼·입력·계정 메뉴를 모바일 화면에 중복 노출하지 않는다.
- 보조 작업은 기존 페이지 도구 메뉴를 사용한다. 주요 동작을 보조 메뉴 안에 숨기지 않는다.

- 스크리너 사용 가이드 같은 도움말은 상단 `…` 페이지 도구 메뉴에 둔다. 본문에 접힌 안내 카드나 별도 행으로 다시 노출하지 않는다.

## 접힌 영역은 한 줄 요약 크기로 만든다

- 저평가 신호처럼 접을 수 있는 요약은 충족 개수·짧은 결론·펼침 표시를 같은 행에 배치한다.
- 접힌 상태에는 펼친 패널용 16~24px 상하 패딩이나 최소 높이를 남기지 않는다. 모바일 저평가 신호는 상하 패딩 0, 좌우 12px, 아래 여백 8px을 기준으로 한다.
- 한 줄 문구라면 조작 영역 최소 44px과 테두리 정도의 높이로 표시한다. 긴 문구·글자 확대 시에는 자연스럽게 높아지도록 하고 고정 높이로 내용을 자르지 않는다.
- 펼친 상태에는 상세 지표를 읽을 여백을 유지한다. 접을 때는 상세 내용과 그 내용에만 필요한 여백이 함께 사라져야 한다.

## 모바일 첫 화면에 실제 데이터를 보여준다

- 제목·버튼·탭·설명·카드의 여백을 각각 보는 데 그치지 말고, 합쳐진 세로 높이를 확인한다. 핵심 수치와 첫 분석 항목이 불필요하게 아래로 밀리지 않게 한다.
- 시장 지표와 관심종목은 짧은 행 중심으로 구성한다. 지표마다 큰 카드나 넓은 빈 공간을 반복하지 않는다.
- 현재가·적정가 비교 차트는 동일한 가격 축에 두 값을 서로 다른 모양으로 표시하고, 연결 구간과 현재 시세 대비 차이율을 함께 보여준다. 상세 모델의 과거 계산 기준가와 혼동하지 않도록 기준을 명시한다.
- 적정가치 모델 행과 차트는 숫자·라벨을 읽을 공간만 확보한다. 고정 높이와 위아래 패딩이 겹쳐 생기는 빈 공간을 줄인다.
- 모바일 글자·간격은 스크리너만 별도로 축소하지 않고 서비스 전체의 공통 기준을 따른다. 기본 배율은 `87.5%`(기존 `115%`의 약 76%)로 두어 브라우저에서 75%로 줄인 화면에 가까운 밀도를 제공하고, `rem` 기반 글자·패딩·간격을 함께 조정한다. 이미 작은 고정 `px` 보조 글자는 추가로 축소하지 않는다.
- 화면별 정보 밀도는 패딩·행 간격·중복 요소를 조절해 높인다. 공통 배율 위에 글자 축소를 중복 적용하지 않는다. 주요 터치 영역은 최소 44px, 모바일 입력 글자는 최소 16px로 유지하며 사용자 글자 확대를 막지 않는다.
- 분석의 저평가 요약·읽는 법·적정주가 모델명·가격도 공통 배율을 따르도록 `rem`을 사용한다. 해당 영역의 고정 `px` 글자 크기를 재도입하지 않고, 입력 글자의 최소 16px은 유지한다.
- 모바일 스크리너 목록은 기본 배율에서도 핵심 지표를 한 행에 유지한다. 종목명·티커·거래 배지는 공간이 있으면 같은 줄에 두고, 빈 보조 줄을 예약하지 않는다. 긴 종목명이나 글자 확대 시에는 보조 정보의 줄바꿈을 허용한다.

## 관심종목 시작 화면은 목록부터 보여준다

- 로그인 후 시작 화면은 내 관심종목과 가격·적정주가를 바로 보여준다.
- 목록 앞에 별도 ‘오늘’ 소개, 지난 확인 이후 변화 카드, 확인 완료·수동 새로고침 버튼을 다시 추가하지 않는다.
- 최초 진입과 창으로 돌아왔을 때 자동으로 조회하고, 조회 실패 시에만 다시 불러오기 버튼을 제공한다.

## 헤더와 탭은 현재 대상을 유지한다

- 종목명·티커·현재가는 모바일에서 현재 분석 대상을 알 수 있도록 유지한다.
- 분석 탭은 종목 정보 아래에 두고, 스크롤 중에도 탭 전환을 사용할 수 있게 한다.
- 스크롤 시 기존 헤더의 종목 정보를 공통 고정 상단바로 이어 표시한다. 종목 정보를 잃거나 동일 정보를 여러 행에 계속 반복하지 않는다.
- 헤더·본문의 좌우 시작선은 공통 너비 프리셋을 따른다. 컨테이너 패딩 위에 동일한 바깥 여백을 중첩하지 않는다.

## 수정 완료 전 확인한다

- 320px·390px 모바일에서 긴 종목명·가격·요약 문구가 겹치거나 잘리지 않는지 확인한다.
- 접힘·펼침, 스크롤 전후, 탭 전환 상태에서 불필요한 빈 행이나 빈 여백이 없는지 확인한다.
- 라이트·다크 테마, 글자 확대, 최소 44px 터치 영역을 유지한다.
- 화면을 확인하지 못했다면 확인한 코드·자동 검사 범위와 실제 화면 검증 여부를 구분해 보고한다.
- 사용자가 같은 유형의 수정을 다시 요청하면 해당 규칙을 먼저 보완한다. 일회성 요청을 모든 화면의 규칙으로 확대하지 않는다.

## 근거

- 직접 요청: 비교 추가 버튼을 위로 이동하고, 접힌 저평가 신호의 세로 높이를 축소. PR #1127.
- 직접 요청(2026-11-17): 75%로 축소한 모바일 스크리너와 비슷한 밀도를 기본 배율에서 제공하고, 텍스트 크기·간격 조정을 서비스 전체에 적용.
- 최근 반영 이력: 모바일 적정가치 차트 간격 축소(#1126), 시장 지표 밀도 조정(#1125), 스크롤 시 종목 헤더 축소·이동(#1123).
- 최근 반영 이력: 종목 정보 아래 고정 탭 배치(#1116·#1115), 중복 검색 제거(#1114), 관심종목의 모바일 행 구성(#1117), 검색 진입점 통합(#1106).
- 이 문서는 구현·검토 기준이다. 기존 전체 화면에 적용이나 시각 검증이 완료됐다는 의미는 아니다.
