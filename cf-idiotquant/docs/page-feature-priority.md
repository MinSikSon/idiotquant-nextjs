# 페이지별 기능 노출 기준

2026-11-07 현재 작업본에 적용한 화면 구성입니다. 페이지 간 이동 동선 변경에 앞서,
각 페이지에서 주요 작업을 먼저 하고 부가 기능은 필요할 때 펼쳐 사용하도록 정리했습니다.

| 페이지 | 기본 노출 | 선택해서 펼치기 |
| --- | --- | --- |
| 종목 발굴 | 시장·전략·검색·필터·정렬, 적용 조건, 결과 목록과 비교 진입 | 보기 방식·묶기·복사, 기존 결과 해석·상세 필터·전략 설명 |
| 종목 분석 | 종목 검색·시세·분석 요약, 선택한 분석 탭의 핵심 내용 | 기술적 지표, 상세 투자 지표. 기존 탭·읽는 법·모델별 세부 계산 유지 |
| 종목 비교 | 날짜·종목 입력, 비교표 | 결과 아래 날짜별 변화율 통계, 가격 산정 방식·데이터 기준 |
| 수익 계산 | 기본 계산 조건·결과·자산 구성 추이 | 자산 목표, 연도별 명세, 계산 저장·불러오기, 계산 방식·가정, 상세 모드의 가치 희석·통화량 비교 |
| 가계부 | 월 선택·월별 요약·기입·내역 | 내역 아래 항목별 집계, 자산·부채, 자산 목표 |
| 내 계정 | 계정 정보·관심종목·계정 관리, 신규 사용자 시작 안내 | 관심종목 목록 아래 구성·탄탄함 분석, 신규 사용자 시각화 예시 |

- 핵심 결과를 가리는 팩터 연구 도구는 기존 접힘 동작을 유지하고 발굴 결과 아래로 옮겼습니다.
- 홈·로그인·투자 안내·공유·관리자·게임 페이지는 이번 변경 대상에 포함하지 않았습니다.
- 부가 기능은 구체적인 제목을 항상 보여줍니다. 모바일과 데스크톱에 같은 접힘 기준을 적용합니다.
- 공통 `SecondarySection`은 기본 접힘 상태이고, 처음 열 때 내용을 마운트합니다.
  한 번 연 내용은 다시 접어도 마운트를 유지해 입력·내부 펼침 상태를 보존합니다.
- 로그인 제한과 데이터 저장 방식은 기존 정책을 따릅니다. 비교의 조회 시점·수익률 기준 안내는 접힘 영역 밖에도 짧게 남깁니다.

## 검증

- 타입 검사 통과, 수정 파일 ESLint 오류 0개(경고 13개).
- 최신 main에 이번 변경만 반영한 별도 작업 트리에서 테스트 615개 통과.
- 브라우저: 계산기 기본 접힘, 명세 펼침·접힘, 키보드 재열기와 내부 펼침 상태 유지 확인.
- 브라우저: 계산기 390px 화면에서 접힘·펼침 확인, 문서 가로 너비 390px 확인.
- 브라우저: 비교표와 계산 기준의 기본 접힘·펼침, 분석 주요 지표 탭의 부가 영역 기본 접힘 확인.
- 가계부·내 계정 및 발굴의 로그인 전용 조작은 인증 세션이 없어 실제 사용자 화면 검증을 수행하지 못했습니다.
- 운영 배포는 수행하지 않았습니다.

머지 준비 시 최신 main의 명도·문구·계산기 자산 목표 기능을 보존했습니다. 계산기의 자산 목표도 결과 그래프 아래에서 선택해 펼치도록 정리했습니다.
