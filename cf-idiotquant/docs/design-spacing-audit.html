시작선을 맞추고, 간격으로 묶기

홈·발굴·비교·계산기·가계부·잔고의 바깥 여백과 주요 그룹 간격을 정리했다. 설명과 입력은 가까이, 독립된 패널과 단계는 더 멀리 배치한다.

근거: 큰 효과를 만드는 작은 UI 디자인 팁들의 여백으로 관련 요소 묶기·연속된 선에 맞춰 정렬하기 원칙. 게임·관리자 전용 화면은 적용 범위에서 제외했다.

적용 기준

그룹 내부

설명·제목·입력 레이블은 4·8·12의 간격을 중심으로 배치한다. 비교 설명과 입력 영역 사이에는 16을 두고, 같은 입력 묶음의 컨트롤 사이에는 12를 둔다.

독립된 그룹 사이

잔고 선택기와 패널, 분석 안내 단계는 24, 계산기 조건과 결과는 32를 사용한다. 숫자 표·차트·한 줄 컨트롤의 세부 간격은 역할에 맞게 유지한다.

Tailwind 간격의 숫자는 기본 16px 글자 크기에서의 기준값이다. 공통 좌우 여백은 1rem·1.5rem이며, 기존 모바일 115% 글자 확대 설정에서는 실제 18.4px·27.6px로 확대된다. 홈도 같은 단위와 640px 분기점을 따른다.

브라우저 확인

  • 모바일 320px 홈·비교·발굴·잔고 표본의 왼쪽 시작선은 약 18.4px였다. 390px 계산기도 같은 시작선을 사용하고 조건·결과 사이 간격은 약 36.8px(2rem)이었다.
  • 700px 홈 시작선은 약 27.6px(1.5rem), 1440px 발굴 결과·도움말 시작선은 24px였다. 발굴의 데스크톱 중복 여백이 제거됐다.
  • 1440px 계산기의 좌우 제목 상단과 첫 카드 상단이 각각 일치했고, 두 열 사이 간격은 32px였다.
  • 1280px 홈 도구 카드 3개의 링크 하단이 일치했다. 1440px 홈 소개와 도구 안내의 시작 높이가 일치했다.
  • 잔고 공통 골격 표본에서 선택기 내부 간격 12, 그룹·패널 사이 24를 확인했다. 숨겨진 패널이 앞에 있어도 flex gap에 추가 빈칸이 생기지 않았으며 탭 왕복이 정상 동작했다.
  • 390px 분석 안내 단계 사이 간격은 24px였다. 확인한 모바일·태블릿·데스크톱 대표 화면에서 문서 가로 넘침이 없었다. 라이트·다크 테마를 확인했다.

잔고는 인증 없이 공통 BalanceShell을 사용하는 임시 표본으로 확인했다. 가계부의 인증 데이터 화면과 잔고의 실제 주문·계좌 동작은 실행하지 않았다. 해당 영역은 소스 검토 범위를 함께 기록한다. 임시 검증 경로는 최종 소스에서 제거했다.

자동 검증

최종 소스의 npm run check가 통과했다. 타입 검사와 테스트 586개가 성공했고 lint 오류는 0개였다(기존 경고 129개). npm run build도 통과했다. 최종 빌드에 임시 검증 경로는 포함되지 않는다. CI 결과는 PR에서 확인할 수 있다.
