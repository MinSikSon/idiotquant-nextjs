# 투자 탐색 동선

기본 동선은 **발굴 → 분석 → 관심 저장 → 재방문**이며, 비교는 필요할 때 선택한다.

- 홈: 로그인한 사용자의 관심종목을 먼저 보여 주고, 발굴·분석·관심종목으로 연결한다.
- 발굴: 분석에 들어갈 때 검색 조건과 스크롤 위치를 보관한다. 비교 모드에서는 직접 고른 종목만 전달한다(비회원 4개, 회원 20개).
- 분석: 결과 상단에 목록 복귀, 관심 저장, 비교 추가를 제공한다. 모바일에서는 복귀 문구를 ‘목록’으로 줄인다.
- 관심 저장: 비회원이 저장을 누르면 로그인 후 같은 종목으로 돌아와 저장을 이어간다. 같은 탭의 30분 이내 요청만 처리하며 이미 담긴 종목은 해제하지 않는다.
- 비교: 종목부터 추가하면 최근 거래일 가격으로 시작한다. 날짜 추가·변경은 접힌 보조 영역에서 제공한다.
- 재방문: 홈의 관심종목과 메뉴의 ‘내 관심종목’에서 분석을 이어간다.

## 검증

경로·필터 보존, 저장 요청 유효기간과 중복 방지, 선택 한도는 단위 테스트로 검증한다. 브라우저에서는 모바일·데스크톱 분석 화면, 비회원 로그인 복귀 주소, 종목 선택·해제·한도, 날짜 입력 없는 비교 시작을 확인했다.

실제 OAuth 로그인 완료 후 자동 저장 및 로그인 홈의 관심종목 표시는 인증 세션이 없어 브라우저에서 검증하지 못했다.
