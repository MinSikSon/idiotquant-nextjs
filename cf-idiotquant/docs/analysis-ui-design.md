# 분석 페이지 UI 적용 기준

서비스 UI 통일 작업의 첫 적용 화면은 `/analyze`입니다. 검색, 탭, 계산, 로그인 권한과 공유 흐름은 기존 구성을 사용합니다.

## 화면 규칙

- 배경과 패널, 글자와 보조 설명, 테두리와 강조색은 `analyze.module.css`의 `--analysis-*` 변수에서 관리합니다. 라이트와 다크 테마를 함께 정의합니다.
- 본문 너비는 기존 `PAGE_WIDTH.data`의 좌우 패딩을 유지하면서 최대 1440px로 제한합니다.
- 데스크톱에서는 분석 요약과 도움말을 260px 보조 열에 두고, 모바일에서는 본문 위에 배치합니다.
- 탭과 주요 동작은 최소 44px 높이를 사용합니다. 공통 상단바의 제목·시세·작업 슬롯은 계속 사용합니다.
- 읽는 문장은 14~15px, 지표 이름은 14px, 보조 설명은 최소 13px로 표시합니다. 숫자는 고정 자릿폭을 사용하되 자리 사이를 끊지 않도록 충분한 열 너비를 확보합니다.
- 패널은 16px 모서리와 얇은 테두리, 16~24px 내부 여백을 사용합니다. 지표마다 별도 카드와 그림자를 추가하지 않습니다.
- 시장 지표 열은 최소 220px의 읽기 폭을 확보합니다. 좁은 화면에서는 한 열로 배치합니다.
- 국내·미국 재무표의 첫 열은 고정하고 표 안에서 가로 스크롤합니다. 수치는 15px로 유지하고, 항목명 전체를 누르면 설명이 열립니다.
- 현재가 옆의 비율에는 `NCAV 업사이드`를 명시해 당일 등락률과 구분합니다.

## 재사용 위치

`components/research/research-ui.module.css`는 종목 요약, 시장 지표, 기술적 지표에서 사용하는 표면·제목·수치·간격 규칙입니다. 분석 페이지의 테마 변수를 따릅니다. 다른 서비스로 확대할 때는 먼저 해당 화면의 데이터 밀도와 긴 숫자·문구를 확인한 뒤 공통 토큰으로 옮깁니다.

## 확인 범위

- 실제 삼성전자·애플 검색, 자동완성, 탭 전환과 종목 카드
- 로컬 가상 데이터 및 SEC 테스트 자료로 국내·미국 재무표와 설명 팝업, 시장 지표, 위험 점검
- 320px·390px 모바일과 데스크톱, 라이트·다크 테마
- 로그인 전용 컴포넌트는 가상 데이터를 넣은 임시 로컬 화면에서 확인했으며, 해당 검증 화면은 배포 코드에 포함하지 않습니다.
