검증

  • npm run check: 린트 오류 0개, 타입 검사 통과, 단위 테스트 586개 통과. 기존 린트 경고는 유지되며 Worker 통합 suite는 별도입니다.
  • npm run build: Webpack 프로덕션 빌드 통과.
  • 로컬의 예시 데이터 화면에서 실제 공용 컴포넌트를 렌더링했습니다. 흑백의 밝은·어두운 테마에서 선택 밑줄, 지표 체크, 링크 밑줄과 모바일 너비를 확인했습니다. 검증용 임시 화면은 빌드·커밋 전에 제거했습니다.
  • 예시 비율 카드를 Enter로, 일반 카드를 Space로 열어 각각 1회만 실행됨을 확인했습니다. 내부 관심 버튼을 Space·Enter로 누를 때에는 관심 상태만 바뀌고 분석 열기 횟수는 늘어나지 않았습니다.
  • 공용 보기 버튼을 Enter·Space로 전환한 후 aria-pressed와 실제 밑줄이 함께 바뀌는 것을 확인했습니다.
  • 실제 비로그인 스크리너에서 국내→미국 시장 전환, 모바일 현재 페이지 밑줄, 서비스 메뉴의 현재 페이지 표시를 확인했습니다.
