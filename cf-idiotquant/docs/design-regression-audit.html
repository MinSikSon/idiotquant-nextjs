화면별 예외와 회귀 점검

앞선 일곱 단계의 적용 범위를 소스로 점검하고, 계산기·비교·목표 자산·검색에서 빠진 대비와 조작 영역을 보완했다. 소스·자동 검사와 화면 직접 검증의 결과를 구분한다.

현재 판정: 소스 회귀 점검 및 보완 완료 · 최신 화면 직접 검증 미완료

브라우저 연결 오류와 Mac 잠금으로 6–8단계 변경의 화면 검증이 남았다. 1–5단계의 과거 화면 확인을 최신 변경의 통과 근거로 사용하지 않는다. 전체 화면의 접근성 인증이나 8개 항목의 최종 인수 완료를 뜻하지 않는다.

기준: 큰 효과를 만드는 작은 UI 디자인 팁들. 금융·공통 UI를 대상으로 하며 게임·관리자 전용 화면은 별도 규칙을 유지한다.

대상발견보완

계산기·비교·목표 자산 설명밝은 캔버스 위 neutral-500, 비교 화면의 어두운 테마 보조 글자색 누락관련 보조 글자를 light neutral-600 / dark neutral-400으로 정리했다. 선택·상태의 의미 색상은 유지한다.
검색 초기화·비교 제거·목표 해제작은 아이콘 버튼과 36px 목표 해제 버튼공통 아이콘 버튼과 페이지 보조 버튼으로 최소 2.75rem 조작 영역, 포커스와 비활성 상태를 맞췄다.
검색 combobox결과 없음 팝업이 열려도 aria-expanded가 false이며, 닫힌 팝업의 선택 항목을 참조할 수 있음실제 팝업 표시 조건으로 expanded와 controls를 맞추고, 열린 팝업에 존재하는 선택 항목만 activedescendant로 참조한다.

대비 근거

소스의 색상 토큰을 WCAG 상대 휘도 공식으로 계산한 값이다. 실제 브라우저 픽셀, 투명도 합성, 모든 상태의 실측값은 아니다. 아래 표면에 놓인 일반 입력 경계는 3:1, 보조 텍스트는 4.5:1 기준을 넘는다.

  4. 비교 날짜·종목 추가/제거 및 대기 중 비활성 상태, 계산기 숫자 입력·단위 선택과 자동 결과를 확인한다.

자동 검사는 위 화면 상호작용을 실행하는 E2E 검사가 아니다. 실제 계좌·거래·저장 검증을 완료로 표시하지 않는다. 보고서 자체의 최신 브라우저 렌더링 확인도 같은 연결 제한으로 남아 있다.
