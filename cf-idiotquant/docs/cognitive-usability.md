# 인지 처리 7단계를 기준으로 한 서비스 사용성 개선

2026-11-18. 사용자가 제공한 다음 단계 정의를 기준으로 한다.
감각(Sensation) → 지각(Perception) → 주의(Attention) → 기억(Memory) →
이해·추론(Reasoning) → 판단·의사결정(Decision) → 실행·학습(Action & Learning).
앞서 사용했던 노먼의 행동 7단계 해석은 이 기준으로 교체한다.
이 문서는 제공된 분류를 사용성 점검에 적용하며, 신경과학적 처리 순서를 검증하는 문서는 아니다.

## 공통 검색에 반영한 내용

기존 헤더의 단일 검색 진입점을 유지한다. 홈 목록 앞에 별도 안내 패널을 추가하지 않는다.
이번 추가 구현은 주의·기억 부담을 줄이는 데 집중한다. 앞서 구현한 검색 오류 방지와
피드백도 아래의 사용자 제공 단계에 맞춰 분류한다.

| 단계 | 사용자 관점의 질문 | 적용 내용 |
| --- | --- | --- |
| 감각 | 조작 요소를 알아볼 수 있는가? | 검색 입력·후보의 읽기 크기와 최소 44px 조작 영역을 확보한다. |
| 지각 | 입력·후보·선택 상태를 구분할 수 있는가? | 입력값과 방향키로 선택한 후보를 구분하고, 후보 수와 선택 문구를 표시한다. ARIA로 입력·후보·상태 안내를 연결한다. |
| 주의 | 지금 필요한 정보에 집중할 수 있는가? | **추가:** 입력 중에는 최근 검색과 예시 가이드를 숨긴다. 입력 전에는 최근 검색을 우선 보여주고 기록이 없을 때 예시 가이드를 보여준다. |
| 기억 | 종목명을 다시 떠올려 입력해야 하는가? | **추가:** 이번 방문에서 선택한 알려진 종목을 최근 5개까지 중복 없이 기억한다. 현재 시장·허용 목록에 포함된 종목만 다시 보여준다. 기록 지우기를 제공한다. |
| 이해·추론 | 상태의 의미와 다음 행동을 알 수 있는가? | 후보 없음, 제한 목록 불일치, 목록 로딩 실패를 구분해 검색·재입력·재시도를 안내한다. |
| 판단·의사결정 | 원하는 종목을 골랐는지 확인할 수 있는가? | 첫 후보를 자동 선택하지 않는다. 명시적으로 고른 후보를 검색하고, 선택 제한 상태의 실행은 막는다. |
| 실행·학습 | 실행 결과를 확인하고 다음에 활용할 수 있는가? | Enter·클릭·터치 실행, 한글 조합 보호, Esc 입력 보존, 로딩 재시도를 제공한다. **추가:** 선택한 종목을 다음 검색에서 재사용한다. 분석·비교 결과와 오류 피드백은 기존 페이지가 제공한다. |

최근 검색은 공통 Provider가 유지되는 동안의 메모리만 사용한다. 새로고침하면 사라지며
localStorage나 서버에 별도 기록을 추가하지 않는다. 최근 검색은 조회·분석 성공의 증명이 아니라
검색창에서 알려진 종목을 선택한 기록이다.

## 서비스 전체에 적용할 검토 기준

아래는 후속 화면 변경 시 사용할 기준이다. 이번에 모든 화면을 수정·검증했다는 뜻은 아니다.

- 감각·지각: 가격·단위·기준 시점과 상태를 읽을 수 있게 하고, 상승·하락을 색상과 부호로 함께 표현한다.
- 주의: 관심종목·분석의 핵심 수치를 먼저 보여주고, 설명은 기존 도구 메뉴와 상세 펼침을 사용한다.
- 기억: 현재 종목·탭·적용 필터를 화면에 남겨 사용자가 조건을 외울 필요를 줄인다.
- 이해·추론: 적정가와 현재가를 같은 축에서 비교하고, 계산 가정·결측·기준 기간을 구분한다.
- 판단·의사결정: 비교·관심종목 담기 동작을 현재 종목과 가까이 두고 추정치를 확정적 결론으로 표현하지 않는다.
- 실행·학습: 저장·조회 성공과 실패를 구분하고, 실패 후 입력을 보존하며 다시 시도할 경로를 제공한다.

## 검증 범위

- 회귀 검사: 입력값 검색, 방향키 선택, 한글 조합 Enter, Esc 입력 보존,
  제한 목록의 불일치 차단·후보 클릭, 비활성 상태의 실행 차단.
- 기존 공통 검색 Provider·모바일 검색 입력 전달 검사도 함께 실행한다.
- 로컬 브라우저 제어가 Work 설정에서 비활성화되어 320px·390px,
  라이트·다크·글자 확대·실제 터치 동작의 시각 검증은 수행하지 못했다.
- 최신 `main` 기반의 별도 작업 공간에서 전체 검사를 수행했다. 기존 로컬 작업 폴더는 보존했다.
