# 비교 페이지의 과거 시가총액

환산가는 `실제 거래일의 시가총액 / 조회 시점의 현재 상장주식 수`다.
국내는 기존 최근 200개 일별 저장값을 먼저 확인한다. 해당 거래일의 시총이
없으면 같은 행의 원가격과 당시 주식 수로 계산하고, 둘 다 없으면 외부 API를
조회한다. 미국은 외부 시총 API를 사용하지 않고 기존 종가로 비교한다.

## 서버 환경변수

Next.js 서버의 `.env.local` 또는 배포 환경에 다음 키를 설정한다.
`NEXT_PUBLIC_` 접두사를 붙이지 않는다. 키는 서버에서만 사용한다.

| 환경변수 | 용도 |
| --- | --- |
| `DATA_GO_KR_SERVICE_KEY` | 공공데이터포털의 **디코딩 인증키**. 금융위원회 주식시세정보 V2 활용 신청 필요 |

키 설정 후 서버를 재시작하고 비교 종목 또는 날짜를 다시 추가한다.
기존 로컬 저장값은 자동 갱신하지 않는다.

국내는 `basDt`와 `likeSrtnCd`로 검색한 뒤 응답의 `basDt`·`srtnCd`를
정확히 대조한다. `mrktTotAmt`는 원 단위다. 값이 없으면 같은 행의
`clpr * lstgStCnt`로 보정한다.

키 미설정, 권한 제한, 제공 범위 밖 날짜, 타임아웃에는 환산값을 만들지 않고
사유를 표시한다. 한 날짜라도 환산가가 없으면 해당 종목의 모든 날짜를 종가
기준으로 비교한다. 외부 조회 성공 응답은 CDN에서 하루 캐시하며 실패는
캐시하지 않는다.
