공개 화면 50개 조건 확인

PR #1031의 소스와 동일한 프로덕션 빌드를 로컬에서 열어, 앞서 연결 문제로 남겨 둔 화면 검증을 진행했다. 앱 내 브라우저는 Mac 잠금과 별개로 정상 연결됐다. 이번 변경은 검증 기록이며 제품 소스 수정은 없다.

공개 화면의 반응형 점검 완료 · 인증 기능 전체 인수는 미완료

홈·계산기·분석 시작·비교 빈 결과/날짜 칩·비로그인 발굴 화면에서, 두 테마 × 다섯 화면 폭의 50개 조건 모두 페이지 전체의 가로 넘침이 없었다. 이 수치는 DOM의 viewport/scrollWidth 대조이며 모든 내부 요소의 겹침이나 모든 상태의 시각 검증을 뜻하지 않는다.

반응형 점검

일부 대표 화면의 스크린샷도 확인했다(계산기 light 390px, 분석 dark 390px, 홈 light 1280px, 비교 dark 390px, 발굴 dark 390px). 모바일 root 글자 확대 규칙에 따라 2.75rem은 약 50.6px이 된다. 실제 모바일 기기·모든 브라우저 호환성 검사는 아니다.

실행한 상호작용

대상확인 결과
계산기상세 전환, 초기 투자금 1,000→2,000 변경 후 평가금액 자동 반영(2억 6,262만원→2억 9,521만원), 목표 30,000 입력 후 달성률 98.4% 표시, 목표 해제로 0 복귀. Tab 후 2px 포커스 확인
검색 ARIA빈 입력은 expanded=false·controls/active 참조 없음. 결과 없음은 expanded=true·listbox 존재. AAPL 추천에서 ArrowDown 후 suggestion-1 존재 확인. Escape 후 팝업·참조 제거. 초기화 후 검색 버튼 비활성 확인
비교 날짜키보드 입력 이벤트로 날짜 추가·제거와 종목 검색 활성화를 확인. 자동화 도구의 fill만으로는 DOM 값과 React 상태가 일치하지 않아 단순 fill을 사용자 입력 성공으로 간주하지 않음. 실제 거래일 가격 조회는 수행하지 않음

잔고 공통 컴포넌트와 제외 조건

실제 계좌 대신 임시 로컬 fixture에서 기존 BalanceShell·DetailHelp를 렌더링했다. 개발 서버 준비와 hydration 이후에 상호작용을 확인했으며, fixture는 저장소에 남기지 않는다.

  • 요약→상세→요약 전환 시 해당 패널 표시가 바뀌었다. 페이지 작업 메뉴에서 자동갱신 버튼의 aria-pressed=true 변경을 확인했다. 실제 자동 조회는 연결하지 않았다.
  • 도움말은 Enter로 열리고 닫기 버튼과 Escape로 닫혔다. 390px에서 x=12, 오른쪽=378, 너비=366px로 화면 안에 배치됐다. 닫기 영역은 약 50.6×50.6px이었다. 데스크톱 팝오버 너비는 320px, 반경은 두 환경 모두 8px이었다.
  • 일반 금융 표본의 font-bold 실측은 600, text-sm 줄 높이는 24.15px이었다. 관리자 또는 게임 표식을 넣으면 새 금융 토큰이 제거돼 기존 굵기 700·줄 높이 23px로 돌아왔고, 표식 제거 후 600·24.15px로 복귀했다. 실제 관리자·게임 전체 화면 확인을 대신하지 않는다.

추가 발견과 남은 확인

  • 최초 검증에서 발견한 미래 날짜 추가는 후속 수정으로 보완했다. 날짜 추가·발굴 링크·저장본 복원은 실제 달력 날짜이며 사용자의 오늘 이전인지 공통 검사한다(오늘 포함). 미래 입력은 추가 버튼 비활성·aria-invalid·연결된 오류 안내로 표시한다. 저장본은 잘못된 날짜와 해당 가격만 제외하고 유효한 종목·가격을 보존한다. 프로덕션 화면에서 미래 날짜 입력과 미래 발굴 링크 차단, 정상 과거 날짜 추가·제거·검색 활성화를 확인했다. 전체 타입 검사·테스트 598개와 빌드가 통과했다. 실제 시세 조회와 거래일 해석은 별도 범위다.
  • 실제 계좌·로그인 상세 발굴 필터·저장·거래는 실행하지 않았다. 인증된 잔고 전체 화면과 실제 관리자·게임 화면, 종목 데이터가 있는 비교 표/카드, 상세 분석·리서치의 최종 확인은 남는다.
  • 검색 Enter와 명시적 검색의 요청이 정확히 한 번 실행되는지, IME 조합 및 실제 모바일 날짜 선택기 동작은 이번 실행에서 계측하지 않았다.
  • 측정 결과는 최신 공개 화면의 범위에 한정된다. 전체 서비스의 접근성·거래 기능·브라우저 호환성 인증으로 해석하지 않는다.

검증 환경과 연결

로컬 프로덕션 서버 3112, 임시 컴포넌트 검증 서버 3113, 앱 내 브라우저를 사용했다. 인증 계정 없이 검사했고 원래 작업 폴더의 미커밋 변경은 보존했다. 제품 소스가 동일하므로 이전 타입 검사·테스트 586개·빌드 결과를 재사용하며, 문서의 내부 링크와 변경 범위는 별도로 확인한다.
