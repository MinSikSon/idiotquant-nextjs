# Rogue 작업 목록

- [x] 선택 제단 — 문 하나인 제단방에서 한 번만 위험과 보상 중 하나를 고른다.
- [ ] 유물 조합 — 이미 가진 유물 두 개가 만날 때만 작은 시너지를 낸다.

## 선택 제단 설계 (v1)

### 목표

층을 더 깊이 내려갈 이유가 되는 **한 번짜리 선택**을 만든다. 상점처럼 금화를 쓰지 않고,
던전 생성 규칙이나 영구 사망의 값을 흐리지 않는다.

### 놓이는 자리

- 새 방을 파지 않는다. 이미 있는 `altar` 특수방을 그대로 쓴다.
- 특수방의 조건(계단이 없고, 문이 하나인 방)은 유지한다. 들어가고 나오는 위험이 곧 값이다.
- 제단은 한 층에 하나이며, 같은 제단에서는 한 번만 고른다.
- 지금 제단에 있던 모루는 남긴다. 선택방을 찾는 길과 캠프를 찾는 길이 같은 곳에 서므로,
  방 자체를 공짜 보상으로 만들지 않는다.

### 흐름

1. 제단 칸에 서면 `제단에 바칠 것을 고른다` 단추가 열린다.
2. 세 선택지는 **누르기 전에는 턴을 쓰지 않는다**. 고르는 순간에만 한 턴이 지난다.
3. 고르면 그 층의 제단은 꺼지고, 다른 선택지는 사라진다.
4. 선택 결과와 비용은 `GameState`에 저장한다. 저장을 다시 읽거나 온라인으로 건너가도
   제단을 두 번 쓸 수 없어야 한다.

### 선택지

| 선택 | 즉시 비용 | 보상 | 선택 이유 |
|---|---:|---|---|
| 피의 서약 | 현재 HP의 1/3 (최소 5, 죽는 선택은 잠김) | 축복받은 강화 주문서 1장 | 지금 버티는 힘을 내고 장비 성장에 건다 |
| 굶주림의 서약 | 허기 400 | 지도 주문서 1장 + 감정 주문서 1장 | 체력은 지키되, 식량 여유를 정보로 바꾼다 |
| 수호자의 서약 | 제단방의 적들이 깨어나고 챔피언 수호자가 나타남 | 수호자 처치 시 보석 1개 | 자원 대신 바로 닥친 전투를 감수한다 |

### 지켜야 할 규칙

- 금화는 여전히 점수다. 제단의 비용·보상으로 쓰지 않는다.
- 보상 물건은 일반 드롭 상한을 뚫어 무더기로 얹지 않는다. 기존 제단의 작은 물건 몫을
  선택 보상으로 바꾸고, 한 장만 준다.
- 화면은 선택지를 보일 뿐 비용·보상·사용 완료 여부는 `perform(state, cmd)`가 처리한다.
- 선택지를 고르는 동안 몬스터가 움직이면 안 되지만, 확정한 행동은 한 턴을 쓴다.
- 협동에서는 제단을 쓴 사람의 체력·허기만 비용으로 내고, 보상도 그 사람의 배낭으로 간다.

### 구현 순서

1. 제단 사용 여부와 선택 명령을 게임 상태·저장 형식에 추가한다.
2. `perform`에 비용 검증·보상·한 번 사용 처리를 넣고 단위 테스트를 작성한다.
3. 제단 칸의 행동 버튼과 선택 패널을 만든다.
4. 시드 다수 회귀와 협동·저장 복원으로 제단 중복 사용, 죽는 비용, 보상 상한을 검증한다.

### 유물 조합의 다음 설계 원칙

- 유물 자체 효과를 바꾸지 않고, **두 개를 동시에 가진 경우만** 작은 보너스를 낸다.
- 조합은 처음에는 두 개만 만들고, 배낭·전투·시야 중 이미 있는 계산 자리 하나에만 붙인다.
